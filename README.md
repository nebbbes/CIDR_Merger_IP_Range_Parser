# CIDR Merger & IP Range Parser (IP2Location)

**Графическое приложение на Python** для работы с IP-диапазонами и CIDR.

Приложение позволяет:
- Загружать актуальные IPv4-диапазоны для выбранных стран напрямую с сайта IP2Location LITE (парсинг страниц + скачивание JSON).
- Объединять (сливать) пересекающиеся диапазоны.
- Конвертировать между форматами: `IP-IP` / одиночные IP ↔ CIDR (`IP/префикс`).
- Импорт/экспорт списков в `.txt`.
- Поиск по странам, выбор нескольких стран, статистика загрузки.
- Поддержка русского и английского интерфейса сайта IP2Location.

## Возможности

- Автоматическое слияние диапазонов (эффективный алгоритм).
- Конвертация в компактные CIDR-блоки.
- Многоязычный парсинг страниц IP2Location (RU/EN).
- Сохранение настроек окна и параметров.
- Горячие клавиши и контекстное меню.
- Простой и удобный GUI на Tkinter.

## Требования

- Python 3.8+
- Интернет-соединение для загрузки диапазонов стран.
